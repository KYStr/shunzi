# 順字

在 ChatGPT 網頁裡，幫繁體中文輸入少一點錯字。順字會讀取你正在輸入的短篇草稿，根據上下文提出局部修正，例如「我明天在回覆你 → 我明天再回覆你」和「連載憶起 → 連在一起」，保留原本的語氣。

**目前是早期測試版本。** 尚未完成真實模型品質、速度與一週真人試用驗收；預設只顯示候選，不自動改字。兩秒回應、80% 修復率與 99% 自動修改正確率是驗收目標，並非已達成的保證。GitHub 公開首版發布須先完成 [試用門檻](../PILOT.md)。

**開發方向更新：** 已新增「完整草稿 → 本機同音／跨詞候選 → Jev 選擇」的[段落校對核心原型](../PARAGRAPH-ENGINE.md)，不需要更換系統輸入法，也不需要 Gemini 配合 Jev。下列安裝步驟與現有 ZIP 仍對應原 Gemini 基準版；新核心尚未接入套件設定、候選 UI 或託管 API。

## 選擇版本

| | 自備 API 版（BYOK） | 託管版 |
|---|---|---|
| 適合誰 | 願意自行申請 API 的使用者 | 想直接開始的小規模測試者 |
| 需要的憑證 | 自己的 Gemini API key | 測試啟用碼 |
| 草稿傳送路徑 | 瀏覽器 → Google Gemini API | 瀏覽器 → 順字服務 → Google Gemini API |
| 誰付模型費用 | 使用者直接付給 Google | 由測試額度支付 |
| 是否需要自己架站 | 不需要 | 不需要 |

BYOK 不經順字伺服器，也不回傳使用遙測。託管後端、部署設定及營運資料屬於私有專案，不在這個儲存庫內。

## 自備 API：開始使用

### 1. 取得並安裝套件

公開 Release 上線後，下載該版本的 `shunzi-byok-0.1.0.zip` 與 `SHA256SUMS` 校驗檔。目前若沒有 Release，請使用維護者提供的本機測試包，或依下方原始碼建置步驟產生套件；不要把「沒有 Release」當作安裝錯誤。

1. 把 ZIP **完整解壓縮到固定資料夾**；不要直接開啟 ZIP，也不要安裝後刪除該資料夾。
2. Chrome 開啟 `chrome://extensions`；Edge 開啟 `edge://extensions`。
3. 打開「開發人員模式」，選「載入未封裝項目」或「載入解壓縮」。
4. 選取**直接含有 `manifest.json`** 的資料夾。
5. 將「順字」固定到工具列，開啟它的設定頁。

下載檔案的 SHA-256 可在 PowerShell 用 `Get-FileHash -Algorithm SHA256 .\shunzi-byok-0.1.0.zip` 核對。校驗值應與同一版本附帶的清單一致。

### 2. 申請 Gemini API

到 [Google AI Studio 的 API key 頁面](https://aistudio.google.com/api-keys)建立金鑰，依 Google 的要求設定專案與帳務。確認帳戶能呼叫 `gemini-3.5-flash-lite`；不是只有 Gemini 網頁聊天訂閱就代表 API 已可使用。

API 的可用地區、模型權限、限制與價格以 [Google API 文件](https://ai.google.dev/gemini-api/docs/api-key)及[價格頁](https://ai.google.dev/gemini-api/docs/pricing)為準。請自行設定供應商帳戶可用的額度或預算提醒；本套件顯示的估算不是付款上限。

### 3. 連線並第一次校對

在順字設定頁貼上金鑰並儲存，閱讀資料傳送說明後開啟校對，使用「測試連線」確認可以呼叫模型。連線測試會呼叫 API，可能產生少量費用。

開啟或重新整理 [ChatGPT](https://chatgpt.com/)，在輸入框打入 `我明天在回覆你。`，完成輸入法選字後停一下。若模型提出修正，點擊標記或候選，選擇「再」；也可以保留原文。這個示範句不代表每次都會獲得相同結果。

你可以繼續使用原本的語音輸入工具；順字只處理它產生的文字，不錄音，也不提供語音辨識服務。

## 平常怎麼用

- 完成選字、停止輸入約 600 毫秒後，順字檢查目前草稿；還在組字時不修改文字。
- 不確定的地方提供最多三個候選；選擇候選前保留原文。符合經驗收類型的明確錯字才可開啟自動修改，**此版本尚未啟用任何自動修改類型**。
- 使用「保留原文」或「還原原文」拒絕修改，同一處不會立刻被改回。用「記住原詞」保護常用名稱，可在設定中管理。
- 在輸入框按 Alt + ↓ 開啟候選，用 ↑／↓ 移動、Enter 啟動候選按鈕、Esc 關閉；也可用 Tab 移動。順字不攔截輸入框原本的 Enter 送出。
- 不需要時點輸入框旁的「暫停」，可一鍵停用；按「開啟」恢復，也可在設定頁切換。發生斷線、逾時或超額時，保留原文，仍可正常輸入與送出。
- 修改到達時會核對草稿版本；如果你已經繼續打字或送出，舊結果不應再套用。

目前只支援桌面 Chrome／Edge 的 `https://chatgpt.com/` 輸入框，不支援手機、桌面版 ChatGPT 應用程式或其他網站。網站改版可能使校對暫時失效。

一般純文字段落可原地套用候選。含粗體、斜體或其他內嵌富文字格式的段落，若無法安全保留宿主格式，順字會保留原文並提示手動修改，不會重建整個輸入框。

每則草稿上限 **500 個 Unicode 字元**，包含空格、標點與換行；部分 emoji 可能由多個字元組成。超過上限時整段不校對，不會把截斷的草稿送出修正。人名、數字、網址、程式碼及有歧義的片段採保守處理，仍可能漏字或誤判；重要內容請看過再送出。

順字的目的不是潤稿、翻譯、改語氣、補完句子或統一地區用語。你在草稿中寫「忽略規則」「重寫全文」時，那些文字只是待校對資料。

## 金鑰、資料與費用

金鑰儲存在此瀏覽器設定檔的 `chrome.storage.local`，使用 `TRUSTED_CONTEXTS` 限制網站及 content script 直接讀取。不使用瀏覽器同步、不放進請求網址、不寫入日誌或匯出設定；由擴充套件背景程序透過驗證標頭呼叫固定的 Gemini HTTPS 端點。

**本機儲存不等於硬體保險箱。** 能控制你電腦、瀏覽器設定檔或擴充套件除錯環境的人，仍可能取出金鑰。不要共用金鑰、貼到 Issue 或截圖；外洩時應到 Google 撤銷並重建。在順字按「移除金鑰」只刪除此瀏覽器內的副本並暫停校對，不會撤銷供應商端金鑰。

BYOK 會送出目前草稿、校對指示及必要的保護詞至 Google；不讀取整段 ChatGPT 聊天紀錄。產品不保存草稿全文；輸入與候選仍會暫時存在記憶體以完成校對。Google 的資料使用與保留條款因服務及帳務條件而異，詳見 [完整資料流](../PRIVACY.md)。

你自行支付 BYOK API 帳單。每次停頓、重試或測試連線都可能產生請求；用量估算與實際帳單可能因價格、token 計數和匯率不同而有差異。不需要時請暫停校對。開發與託管試用的 NT$300 專案預算**不是每位 BYOK 使用者的 API 額度**。維護者的付費驗收另受本機 NT$55、託管驗收 NT$5、託管試用 NT$210 限制，並保留 NT$30；詳見 [驗收預算](../EVALUATION.md)。

## 常見問題

| 狀況 | 可以怎麼做 |
|---|---|
| 401／403、金鑰無效或沒有權限 | 確認金鑰完整、尚未撤銷，專案允許 Gemini API，帳務、地區及模型權限符合 Google 要求。託管版則檢查啟用碼。不要把金鑰附在問題回報中。 |
| 429、超過限制 | 等待後再試，查看供應商的速率與配額；避免同時開太多正在輸入的分頁。連續重試可能繼續消耗額度。 |
| 模型不存在／無法使用 | 確認帳戶支援基準模型，查看官方模型文件及套件更新。本版不是可輸入任意 API URL 的通用客戶端，不會自動轉用其他付費服務。 |
| 沒看到任何校對 | 確認已啟用、已儲存金鑰、連線測試成功、網址是 chatgpt.com、文字不超過 500 字元；完成輸入法選字後停一下。原文可能沒有模型判定的錯字。重新整理頁面可修復更新後失效的連線。 |
| VPN、防火牆、公司網路或離線 | 檢查瀏覽器是否能連到 Gemini API；依所在網路的規範處理連線問題。順字無離線模型，失敗時保留原文。 |
| 改錯了或不想改 | 使用「還原原文／保留原文」；名稱可用「記住原詞」。必要時點「暫停」，照常編輯草稿。 |
| 能直接用 ChatGPT 或 Gemini 訂閱付費嗎 | 網頁聊天訂閱與 API 帳務是不同服務；以供應商帳戶實際 API 權限和帳務為準。 |
| 已刪除金鑰仍看到帳單 | 本機刪除不撤銷金鑰，也不取消已發生的請求或其他應用的使用；請到供應商平台檢查與撤銷。 |
| 想使用 Jev | 已有獨立的[段落候選＋Jev 核心原型](../PARAGRAPH-ENGINE.md)。目前可用命令列驗證；現有套件的 Gemini 欄位還不能填 Jev 金鑰。 |

### 更新與移除

更新前保留目前 ZIP 以便退回。下載新版本，核對校驗值，解壓後替換**原安裝資料夾**的檔案，再到擴充功能管理頁按重新載入，並重新整理 ChatGPT。保留同一安裝資料夾可減少載入成另一個擴充功能而失去設定的情況；套件不備份或匯出金鑰。

若需要還原舊版，以同樣方式放回先前版本；瀏覽器及網站變動可能使舊版不相容。不要同時啟用兩份順字。

解除安裝前可先刪除金鑰，再到擴充功能管理頁選「移除」。如要停止這把金鑰在所有地方的使用，另至 Google 撤銷金鑰。

## 從原始碼建置

使用 Node.js 24 與 npm。先安裝相符的 Node 版本，在儲存庫目錄執行：

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run test:browser
npm run release:scan
```

`npm ci` 使用提交的 lockfile。建置結果在 `dist/byok` 與 `dist/hosted`；ZIP 和 `SHA256SUMS` 在 `release`，版本由 `package.json` 決定。BYOK 測試包為 `shunzi-byok-0.1.0.zip`，託管包為 `shunzi-hosted-0.1.0.zip`。可直接載入 `dist/byok` 測試。本機產生 ZIP 不代表已完成真人試用或公開發布。託管包必須由維護者設定實際服務位址，不能只貼 Gemini 金鑰就當 BYOK 使用。

瀏覽器測試使用 Playwright 與本機 Microsoft Edge（`channel: 'msedge'`），目前完整驗收環境為 Windows，需先安裝 Edge；`npm ci` 不會替你安裝 Edge。先建置再執行 `npm run test:browser`，才能同時檢查模擬輸入框與未封裝 MV3 套件。未安裝 Edge，或尚未完成非 Windows 平台的測試適配時，瀏覽器檢查失敗／無法執行代表「尚未驗證」，不能記為通過。

核心、網站適配層與模型呼叫分離；`POST /v1/check` 的公開資料型別見 `src/core/types.ts`。API 請求包含目前草稿、版本及保護詞，回應包含局部修正、候選與原版本。後端不得將供應商憑證回傳給套件。

測試使用 mock 不代表中文品質或真實速度達標。付費模型驗收、保留集隔離、費用上限與指標定義見 [EVALUATION.md](../EVALUATION.md)；五人試用記錄見 [PILOT.md](../PILOT.md)。
