# 招募材料與匿名回饋

以下兩篇是**未發布草稿**，由使用者自行張貼。正式發碼須先通過 [PILOT](PILOT.md) 的開始條件；目前只適合徵集意願，不得暗示已能購買、已完成五人試用或已有客戶。發布前補上由使用者指定的報名方法，不放私人啟用碼或付款資訊。

## 社群貼文一：常用語音輸入的人

> 你有沒有講完一段中文，還要回頭把「在／再」或整串同音錯字改回來？
>
> 我正在做「順字」：在 ChatGPT 網頁的草稿裡，只提出可能需要改的地方。你可以選候選、保留原文或還原，不會直接替你重寫語氣。它接在你原本的語音輸入後面，不錄音，也不用換輸入法。
>
> 想找最多 5 位平常會在電腦用繁體中文語音輸入的人，先登記試用意願。版本通過實機檢查後，安排 7 天／100 次成功校對的免費託管試用；期限從發碼時計算，不需自己申請 API。每天願意用約一分鐘回報哪裡有幫助、哪裡反而礙事就好。
>
> 目前仍是早期測試，沒有保證每個錯字都能修好。後續在品質與成本條件達標後，才考慮 NT$99／30 天／500 次；現在不收款、不自動轉付費。
>
> 有興趣可回覆「想試」，或用發文者提供的報名方式。請不要貼私人草稿、錄音或金鑰。

> 有興趣請回覆你用 Chrome 還是 Edge、平常語音或打字，以及是否願意自行安裝。不要貼 key 或私人內容。GitHub 版走文件自助支援，不提供 API 購買或電腦設定代辦。

## 報名條件與最少欄位

先確認願意在桌面 Windows Chrome／Edge 使用 ChatGPT 網頁、常用繁中、能接受早期版本可能漏判，並在七天內至少四天有使用機會。接受草稿經 API 處理，且不以機密或敏感內容試用；使用者可隨時停止，不以回饋換取正面評價。

| 報名欄位 | 格式／用途 |
| --- | --- |
| 聯絡方式 | 只由發文者私下保存；不進 Git、不在公開留言要求提供 |
| 瀏覽器／作業系統 | Chrome 或 Edge、Windows 版本；確認支援環境 |
| 主要輸入方式 | 既有語音工具／打字／兩者；不用提供錄音 |
| 常見困擾 | 自己改寫的一句合成例子，選填 |
| 安裝方式 | 願意只依 README 自裝 BYOK／希望託管發碼 |
| 七天使用機會 | 能否至少四天使用，與預計可開始日期 |
| 回饋與資料說明 | 確認讀過隱私說明、知道可停止，且不提供私人草稿 |

錄取後由維護者分配 P1–P5。代號與聯絡方式的對照表單獨私有保存，公開試用表只留代號。至少安排一位尚未被口頭教學的人做 README 自助安裝；不能用有開發背景的一人成功推論所有人都容易使用。

## 回饋訊息模板

每日由測試者自願填寫：`代號／日期／今天有用嗎／成功校對幾次／接受幾次／不需要的候選或還原幾次／最卡的一件事`。範例文字須重新改寫，不能要求轉寄完整聊天、API 錯誤正文或金鑰。

七天後詢問：「你會想保留嗎？哪個情境最有用？哪個情境讓你想關掉？如果未來品質穩定、NT$99／30 天／500 次，你會買、先不買，還是有條件才考慮？」不把自由回答改寫成好評。

付款抉擇另依 PILOT 的三天流程。成本 gate 未通過時只能記意願；真實收據、交易日期與 paid 開通欄保持空白。沒有寄出訊息、沒有回覆或沒有實際付款，都不能填成已完成。
