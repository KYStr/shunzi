# 順字｜說完之後，少花時間修錯字。

順字在 ChatGPT 網頁草稿中提出局部修正，例如「明天在回覆 → 明天再回覆」及「連載憶起 → 連在一起」。接在你原本的語音輸入後面，也支援打字草稿；保留你的語氣，不潤稿、不翻譯，不需要更換系統輸入法。

**0.2.0 的 Jev 套件與託管服務已整合，現階段先供本人測試；公開發布與收費仍為 BLOCKED。** 凍結核心修復 87/100 個人工構造錯句，正確／歧義句 100/100 保留。真實 Edge 擴充套件＋Jev 在本機合成測試頁完成 BYOK 30/30 次預期候選、P95 1,849 ms，託管 6/6、P95 1,847 ms，均含 600 ms 停頓；這不是實際 ChatGPT 網站或語音辨識驗收。本人兩天、五人七天、他人自助安裝和真實成交仍未完成，自動修改保持關閉。[實作紀錄](docs/STATUS.md)與[聚合驗收證據](docs/evaluation-report.json)分開列出結果與限制；[0.1.0 安裝文件](docs/history/README-0.1.0.md)僅供舊版參考。

## 兩種使用方式

| | 自備 API 版（BYOK） | 小規模託管試用 |
| --- | --- | --- |
| 你提供什麼 | 自己的 TypeSafe／Jev API key | 維護者核發的啟用碼 |
| 需要 Gemini 嗎 | **不需要** | **不需要** |
| 模型費用 | 自己直接付給 TypeSafe | 使用託管額度 |
| 架站 | 不需要 | 不需要 |
| 草稿路徑 | 套件背景程序 → Jev | 順字服務 → Jev |
| 方案 | 開源、自助安裝；沒有託管套餐次數 | 擬提供 7 天／100 次試用，最多 5 人 |

候選由固定本機詞庫產生，Jev 只從候選中選擇或保留原文，不自由改寫整段。BYOK 不連順字伺服器，也不傳回遙測；核心可以替換選擇器。這是重用輸入法做法，沒有進行 AI 訓練或蒸餾。[核心說明](docs/PARAGRAPH-ENGINE.md)

託管後續方案擬為 **NT$99／30 天／500 次，最多 5 人**，時間或次數先到即止，不自動續費。試用 7 天從管理員發碼時起算；付費 30 天從管理員開通時起算，均非第一次貼碼。**品質與成本 gate 通過前不販售、不收款**；目前是待驗證的方案，不是已開賣服務。試用、付款意願及真實收據分開記錄，不能用一句「願意買」代替收到款項。[試用與收費前門檻](docs/PILOT.md)

託管次數按成功校對計，無候選不呼叫、不扣次；供應商失敗／未知結果不扣成功次數，但成本預留仍占帳本。相同已成功草稿 snapshot 不重扣。實際到期時間與剩餘次數以服務回傳為準。

## 安裝 Jev 自備 API 版

### 1. 取得測試包

0.2.0 本機測試包與 `SHA256SUMS` 已產生並通過工程及發布掃描，BYOK 檔名為 `shunzi-byok-0.2.0.zip`。公開 Release 仍未發布，請使用維護者提供的包；[固定校驗值](docs/INSTALL.md)可供核對。沒有公開 Release 不算安裝失敗。請勿從不明來源下載或把 API key 交給別人代填。

1. 完整解壓 ZIP 到固定資料夾，安裝後保留該資料夾。
2. Chrome 開啟 `chrome://extensions`；Edge 開啟 `edge://extensions`。
3. 開啟「開發人員模式」，按「載入未封裝項目／載入解壓縮」。
4. 選擇直接含 `manifest.json` 的資料夾。
5. 固定「順字」到工具列，開啟設定頁。確認版本為 0.2.0、設定對象是 **Jev API key**。若仍寫 Gemini，請停止並核對包的版本。

PowerShell 可用 `Get-FileHash -Algorithm SHA256 .\shunzi-byok-0.2.0.zip` 核對同版校驗清單。[圖文安裝說明](docs/INSTALL.md)已附實際套件的 [Jev 設定圖](docs/assets/options-byok.png)、[託管設定圖](docs/assets/options-hosted.png)及[本機測試頁候選圖](docs/assets/candidate-review.png)。圖片不是他人已自助安裝成功的證據。

### 2. 申請及保存金鑰

到 [TypeSafe 控制台](https://console.typesafe.ai/)登入並依官方帳戶流程建立 API key，確認可使用 Jev。帳務、配額、價格與可用地區以供應商帳戶及[官方快速開始](https://docs.typesafe.ai/introduction/quickstart)為準；ChatGPT 或 Gemini 網頁訂閱不能當成 Jev API key。

在順字設定頁貼上自己的金鑰、儲存，閱讀資料說明後啟用。用「測試連線」確認權限；連線測試可能產生 API 費用。一般託管試用者只填啟用碼，不需要自己申請 API。

### 3. 第一次校對

重新整理 [ChatGPT 網頁](https://chatgpt.com/)，輸入 `我明天在回覆你。`，完成輸入法選字後停一下。若出現「再」的建議，點選後確認原意；也可以保留原文或還原。這是功能示範句，不是每次必然成功的承諾。

語音輸入照原本的方式使用。順字只處理已變成文字的草稿，**不錄音、不使用麥克風，也不替你做語音辨識**。

## 平常怎麼用

- 停頓約 600 毫秒後檢查目前草稿；輸入法還在組字時保留文字。
- 預設只提建議，使用者明確選擇後才改。**0.2.0 不開自動修改**。候選可切換、保留與還原；手動決定才可影響本機偏好。
- 不需要時暫停。斷線、逾時、金鑰失效或超額應保留原文，讓你繼續輸入與送出。
- 每次結果須核對草稿版本；續打、換對話或送出後，不套用舊結果。
- 候選可透過鍵盤操作；實際快捷鍵與按鈕名稱以交付包的 [安裝驗收](docs/INSTALL.md)為準。

首版只支援桌面 Chrome／Edge 的 `chatgpt.com`，優先驗證 Windows；不支援手機或 ChatGPT 桌面應用程式。草稿最多 **500 個 Unicode 字元**，包含空白、標點與換行，部分 emoji 占多個字元；超出時整段暫不校對。

目前候選主要涵蓋 1～8 字的多讀音、跨聲調及跨詞混淆，另有相鄰重複字刪除。最多 8 個不重疊區段、每組最多 6 個選項含原文。人名、數字、網址、程式碼、引用錯字、任意模糊音、語音漏字／多字仍可能漏判或誤判。沒有候選不代表沒有錯。富文字無法安全替換時保留原文並手動修改。

## 資料、金鑰與費用

金鑰只存在本機 `chrome.storage.local`，設定 `TRUSTED_CONTEXTS`，禁止網頁及 content script 直接讀取；不雲端同步、不放 URL、不寫入日誌或設定匯出。背景程序只呼叫固定 Jev HTTPS 端點，不接受網頁指定任意網址或索取金鑰。[資料流](docs/DATAFLOW.md)

本機保存不是加密保險箱；能控制本機設定檔或除錯工具的人仍可能取出金鑰。移除本機金鑰會暫停校對，但不會撤銷 TypeSafe 端金鑰。外洩時須到供應商撤銷。不要在 Issue、截圖或回饋中提供金鑰、啟用碼或私人草稿。

啟用後，即使尚未按 ChatGPT 送出，草稿也可能已傳給 Jev。產品不持久保存草稿或修正全文；暫存於記憶體以完成候選與還原。供應商有自己的資料政策，不能把「順字不保存」說成「任何一方都不保存」。[隱私說明](docs/PRIVACY.md)

BYOK API 費用由使用者自行支付。套件估算不能取代供應商帳單與額度控制；停頓、重試與測試連線都可能產生請求。維護者自己的驗收仍受 NT$300 專案總額限制：本機 55、託管驗收 5、試用 210、緩衝 30。[評測規則](docs/EVALUATION.md)

## 排錯、更新與解除安裝

401／403、429、模型不可用、網路、沒有候選、金鑰清除、更新與還原請先看 [FAQ](docs/FAQ.md)。GitHub 版採自助支援，不承諾逐一協助購買 API、付款、公司網路或電腦設定。

更新前保留舊 ZIP。驗證新包校驗值後替換原安裝資料夾的檔案，到擴充功能管理頁重新載入，再重新整理 ChatGPT；不要同時啟用兩份。保留同一路徑可減少被視為另一套件而失去設定的情況。更新或回退後仍須確認憑證、偏好和模型相容性，0.1.0 的 Gemini key 不會自動變成 Jev key。

解除安裝前可刪除金鑰，再到擴充功能頁按「移除」。若要停止該金鑰在所有應用中的使用，另至 TypeSafe 撤銷。

## 原始碼與開發

使用 Node.js 24 與 npm，在儲存庫目錄執行：

```sh
npm ci
npm run paragraph:prepare
npm run typecheck
npm test
npm run build
npm run test:browser
npm run release:scan
```

詞庫準備是建置前必要步驟，下載公開固定資料並驗證快取版本／雜湊，不呼叫付費模型。建置結果預期在 `dist/byok` 與 `dist/hosted`，ZIP／校驗清單在 `release`；版本依 `package.json`。Windows 瀏覽器測試需已有 Microsoft Edge，mock 測試不證明實際 Jev 品質。套件建置或掃描成功，也不等於試用／銷售 gate 通過。開發與凍結保留集的 `paragraph:eval -- --split dev|holdout --label UNIQUE --live` 使用條件見 [EVALUATION](docs/EVALUATION.md)，不可為改善分數反覆調整後重用保留集。

套件、校對核心與接入程式採 [MIT](LICENSE)；託管後端及營運資料保持私有。第三方詞庫須附 [McBopomofo／libtabe notices](third_party/mcbopomofo-web/README.md)，不可只套用順字的 MIT。請勿提交 `.local`、API keys、私人帳本或試用者聯絡資料。
