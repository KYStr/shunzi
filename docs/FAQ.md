# 順字 0.2.0 FAQ

0.2.0 的方向是「本機候選＋Jev」，不需要 Gemini。正式交付、收費與試用狀態以 [PILOT](PILOT.md) 為準；以下不代表尚未驗收的操作已通過。

| 問題 | 處理方式 |
| --- | --- |
| 為什麼需要 API key？ | 本機詞庫找候選，Jev 判斷上下文。BYOK 金鑰識別你的 TypeSafe 帳戶並由該帳戶支付 API；一般託管使用者填啟用碼即可。 |
| 需要 Gemini／ChatGPT API 嗎？ | 不需要。Jev 金鑰與 Gemini 金鑰不同。看到 Gemini 設定代表仍在使用舊 0.1.0 包，請核對版本；不要把 Jev key 填進 Gemini 欄。 |
| 401／403、金鑰無效或權限不足 | 確認使用完整 TypeSafe API key，沒有空白、撤銷或過期；核對供應商帳務、地區及模型權限。託管版確認啟用碼。不要把憑證或完整錯誤回應貼上 Issue。 |
| 429、限流或超額 | 查看供應商／託管方案剩餘額度，稍後再試，減少同時輸入的分頁。不要連續按測試；重試可能仍產生費用。 |
| 模型不存在／暫不可用 | 查看套件版本與 [TypeSafe 官方文件](https://docs.typesafe.ai/introduction/quickstart)。目前固定模型 `jev-1.13.0`，沒有任意 API URL 欄位，不自動換供應商或轉用順字付費帳戶。 |
| VPN、防火牆、離線 | 檢查所在網路能否連到 `api.typesafe.ai`，遵守公司網路規範。候選在本機產生，但語意選擇需要連線；失敗保留原文。 |
| 沒有校對出現 | 確认是桌面 Chrome／Edge、`chatgpt.com`、已啟用且憑證有效、草稿不超過 500 字元。完成輸入法選字後停一下。也可能沒有可用候選，並不表示原文完全正確。 |
| 剛更新完沒有反應 | 在擴充功能管理頁重新載入，再重新整理 ChatGPT。只保留一份啟用中的順字，核對版本、安裝資料夾與金鑰類型。 |
| 語音錯字還是沒修到 | 本版處理辨識後的文字，不做錄音辨識。候選字音、詞库、區段及改動數有上限；相鄰重複字可有刪除候選，任意漏字、多字或模糊音仍未完整涵蓋。 |
| 文字改錯／名稱不該改 | 選「保留原文／還原」，必要時暫停；名稱使用保護詞功能。以去識別合成例句回報，不要直接提交私人草稿。 |
| 會自動改嗎？ | 0.2.0 維持建議模式，明確選候選才套用。少量成功示範及模型 confidence 都不等於 99% 自動修改品質證據。 |
| Jev key 存哪裡？ | 此瀏覽器設定檔的 `chrome.storage.local`，限制為 `TRUSTED_CONTEXTS`。不使用雲端同步、URL 或日誌；能控制本機的人仍可能取得金鑰。 |
| 刪除金鑰為什麼還有帳單？ | 本機清除不撤銷供應商金鑰，也不取消已發生或其他應用的請求。到 TypeSafe 控制台查帳及撤銷。 |
| API 估算會保證不超帳嗎？ | 不會。BYOK 直接付供應商，估算與實際 token、匯率、費率可能不同。自行設定可用的帳戶限制；不需要時暫停。 |
| 7 天／100 次是否等於 BYOK 免費額度？ | 不是。那是待驗收的託管試用，由管理員發碼時計時，非首次填碼。BYOK 自己的 TypeSafe 帳單另計。 |
| 什麼情況扣託管次數？ | 成功校對才扣；無候選不呼叫也不扣。供應商失敗／未知結果不扣成功次數，但成本預留保留；相同已成功 snapshot 不重扣，可能回 409。 |
| 能買 NT$99 方案嗎？ | 目前不能。擬定 30 天／500 次、最多 5 人；成本及其他銷售 gate 未通過前不收款、不開通 paid。 |
| 如何更新／退回？ | 保留舊 ZIP，核對新包 SHA-256，替換原安裝資料夾並重新載入、整理 ChatGPT。回退後檢查設定相容性；不要同時啟用兩份。 |
| 如何移除？ | 先移除本機金鑰，到瀏覽器擴充功能頁按移除。要讓金鑰在所有地方失效，另外到 TypeSafe 撤銷。 |

GitHub 版提供文件與可重現問題回報，採自助支援，不承諾個別協助 API 購買、付款或電腦設定。問題回報請附版本、瀏覽器、去識別重現步驟及預期／實際結果；不要附金鑰、啟用碼、私人網址、私人聊天、未遮蔽截圖或網路標頭。
