# 順字資料與隱私說明

版本：0.1.0；更新日期：2026-10-05。這份文件說明產品設計及設定範圍，不表示尚未部署的託管服務已經上線。正式試用前，維護者須核對部署環境與此文件相符。

## 兩條資料路徑

| 資料 | 自備 API 版 | 託管版 |
|---|---|---|
| 目前輸入框草稿 | 套件背景程序直接傳給 Google Gemini API | 透過 HTTPS 傳給順字 `/v1/check`，再傳給 Google Gemini API |
| 校對指示與保護詞 | 傳給 Gemini 以限定修正範圍 | 經順字服務傳給 Gemini |
| Gemini API key | 存在使用者本機，以驗證標頭傳給 Google | 僅由私有伺服器保存，不提供給瀏覽器 |
| 啟用碼 | 不使用 | 本機保存，以驗證標頭傳給順字服務 |
| 模型回應與候選 | 暫存在校對程序與畫面記憶體 | 由伺服器轉交套件，暫存在處理程序與畫面記憶體 |
| 用量與診斷 | 本機提供用量估算，不傳順字遙測 | 必要的費用、請求時間、延遲、狀態及限流資料供預算管理 |

只在啟用校對後處理目前輸入框。套件不讀整段對話、不錄音、不取得麥克風；既有語音工具及 ChatGPT 本身的資料處理由其各自條款決定。

BYOK 沒有呼叫順字伺服器的退路。金鑰失效、額度用盡或模型不能使用時，只保留原文並提示，不把草稿改送到我們的付費帳戶。

## 本機保存什麼

本機設定包含金鑰或啟用碼、是否啟用、保護詞以及用量估算所需的統計。產品不將草稿及候選全文存入本機持久儲存，也不把它們寫到日誌。完成校對、套用與還原所需的文字會在記憶體中暫存；重新整理頁面會清除這次編輯狀態。

`chrome.storage.local` 使用 `TRUSTED_CONTEXTS`，限制 content script 直接讀取。網站只可透過受限校對介面獲得必要狀態與候選，不能指定任意供應商網址、標頭或要求金鑰。金鑰不放 URL、不使用 `storage.sync`、不寫入日誌，也不包含在設定匯出。

這些限制不能阻止有本機管理權限、能操作瀏覽器設定檔或擴充套件除錯工具的人取得憑證。本機保存不等於加密保險箱。若使用共用電腦，結束後刪除本機金鑰，必要時到供應商撤銷。

「刪除金鑰」會移除本機副本並關閉校對；不會撤銷 Google 端金鑰。保護詞可在設定頁刪除。移除擴充功能後，若要確保憑證不再可用，仍應到供應商端撤銷。

## 託管服務保留什麼

託管服務不得持久保存草稿、完整候選、完整模型請求或回應、Authorization 標頭與供應商金鑰。錯誤處理及反向代理也不得記錄請求正文或驗證標頭。

服務可保留預算預留與結算、匿名化的啟用碼識別、請求識別、時間、token 數、估算費用、結果狀態及限流資料，以防止重複計費和超過 NT$300 專案預算。這些紀錄不應用來重建草稿。第一輪試用結束後由維護者人工稽核所需紀錄，再公布正式資料保留期限；**目前不能宣稱已有特定期限的自動刪除機制**。

五人試用表由測試者自願填入去識別化統計或範例；不是背景自動收集聊天內容。聯絡資料、邀請名單及未匿名紀錄不能提交到公開 GitHub。

## 模型供應商的資料處理

Google 會接收實際送出的短篇草稿、校對指示和必要保護詞，並以 API 金鑰所屬帳戶處理請求。Google 的資料保留、濫用監控及是否用於改善產品，需依你使用的是免費或付費服務、帳務狀態與適用條款判斷；本產品不替供應商承諾「完全不留存」。

啟用前請閱讀 [Gemini API 額外服務條款](https://ai.google.dev/gemini-api/terms)與[API key 文件](https://ai.google.dev/gemini-api/docs/api-key)。若草稿不適合交給該服務，先暫停校對。即使最後沒有按 ChatGPT 的送出鍵，草稿也可能已經因停頓校對而傳給模型。

Jev 尚未成為必要服務；現行 BYOK 初次設定只需 Gemini。若之後將 Jev 加入產品，須先更新此文件，清楚說明新增接收者與傳送內容，再開放使用。

## 問題回報

使用人工重寫、去識別的短例句說明問題；刪掉姓名、電話、帳號、地址、公司內部資訊、私人連結與憑證。不要貼完整 Gemini 錯誤回應、網路請求標頭、瀏覽器設定檔或 API key。若已公開憑證，先在供應商端撤銷；刪掉 Issue 文字本身不能使金鑰失效。
