# 順字 0.2.0 資料與隱私說明

更新：2026-10-05。0.2.0 已整合本機候選＋TypeSafe Jev，BYOK 不需 Gemini；託管新版已部署於 `proof.040141.xyz`。[0.1.0 隱私說明](history/PRIVACY-0.1.0.md)保留為舊版紀錄。以下是目前資料契約；已完成本機合成宿主的真實 Edge／Jev 測試，不代表實際 ChatGPT 或真人試用已通過。[資料流圖](DATAFLOW.md)

## 處理及傳送範圍

只在使用者啟用後讀取目前輸入框，不讀完整聊天紀錄、不錄音、不取得麥克風。既有語音工具、ChatGPT 自身的資料處理各自依其服務條款。

本機固定詞庫產生字音候選，再把目前草稿、必要保護詞、候選與選擇指示交給 Jev 判斷。BYOK 由背景程序直接送往固定 `https://api.typesafe.ai/v1/systemone`；託管版先經順字 HTTPS `/v1/check` 驗碼、限流、預留並轉給 Jev。供應商只能回候選 ID，不改成自由生成整段。

啟用後，**即使尚未按 ChatGPT 的送出鍵**，草稿也可能已因停頓檢查而送到 API。無候選時可直接保留，不呼叫 Jev。BYOK 無順字伺服器備援，也不回傳順字遙測；key 失效、斷線或超額，不會切換到我們的付費帳戶。

## 本機保存與金鑰

本機設定包括 key 或啟用碼、是否啟用、保護詞及用量估算。明確選詞偏好若由交付版本持久保存，也只在本機；它可能包含使用者選取的詞項，不能說完全沒有使用者資料。產品不持久保存整段草稿與完整候選；文字只在校對、顯示及還原所需的記憶體暫存。

金鑰保存於 `chrome.storage.local`，設定 `TRUSTED_CONTEXTS`，禁止網站與 content script 直接讀取。不用 `storage.sync`、不放 URL、不寫日誌或設定匯出；只透過驗證標頭送給相應服務。網頁不能指定任意網址／標頭或要求回傳 key。這不阻止能控制本機設定檔及除錯環境的人取得憑證。

刪除金鑰會移除本機副本並暫停校對，不會撤銷 TypeSafe 端金鑰。外洩時另到供應商撤銷；解除安裝也不取消已發生的 API 帳單。不要將 key、啟用碼或未遮蔽設定畫面貼到公開回報。

## 託管端保存

伺服器需要私有供應商憑證來呼叫 Jev，須以受限服務設定保存，不寫入日誌或回傳瀏覽器。請求草稿、候選、完整模型請求／回應和驗證標頭不可持久寫入應用或反向代理日誌。

可保存啟用碼的不可逆識別、方案／發碼及到期時間、成功校對次數、請求與 snapshot 去重識別、成本預留與結算、時間、token、估算費用和失敗狀態。這些紀錄用於配額、重複請求防護及預算；不應用來重建草稿。使用者成功次數與成本紀錄分開，供應商失敗／未知結果可保留成本預留但不扣成功次數。

目前沒有已完成的特定保留期限及自動刪除驗證，不能對外宣稱「七天自動刪除」。開放試用前須由維護者確認最少保存範圍，提供聯絡及刪除請求方式，並在實際部署後記錄其執行方式。

## 供應商資料條款

TypeSafe 的[隱私政策](https://typesafe.ai/legal/privacy-policy)涵蓋 API 輸入，並聲明不以輸入訓練或微調模型；這不等於不留存輸入或不使用服務供應商。實際服務依帳戶適用條款辦理。網站的[使用條款](https://typesafe.ai/legal/terms)亦指出另行簽訂的產品／服務協議可能另行管轄。

順字不替供應商承諾零保留。開啟校對前，請確認草稿適合交給該服務；不適合的內容先暫停。若未來更換選擇器或增加接收者，須先更新資料說明，不能無提示改送其他 API。

## 回饋與開發資料

五人試用只以 P1–P5 代號填統計，聯絡對照表、付款證明、啟用碼及原始訊息留在私有位置。公開回報使用重新改寫的合成例句，不要求上傳私人草稿、錄音或供應商完整錯誤。付款證據只有實際收到才記錄，不把測試交易當收入。

開發用 `.local` 報告可能保存人工構造的例句與評測結果，是受控開發資料，不是產品默默收集的使用紀錄；不進 repo／ZIP。第三方公開詞庫及授權聲明則按各自授權隨包附帶。
