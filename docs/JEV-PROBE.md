# Jev 可行性小測試

> 歷史紀錄：以下是 0.2.0 整合前的小規模探測，保留當時結果與限制。新版已接入 Jev 套件及託管服務，不需 Gemini；目前狀態見 [STATUS](STATUS.md)。下文「尚未接入」只描述當時，不是新版阻礙。

2026-10-05，依使用者澄清的 Jev 產品方向，直接測試 Jev，不呼叫 Gemini。API 認證與 8 次推論均成功。呼叫 `jev-latest`，8 次實際回報模型皆為 `jev-1.13.0`；後續正式驗證應固定版本。

## 能力與分工

Jev 不依賴 Gemini。官方 [Introduction](https://docs.typesafe.ai/introduction) 與 [Choice](https://docs.typesafe.ai/primitives/choice) 說明：Jev 回傳既定選項、評分或真假判斷，不生成任意修正文字。

可優先研究「本機同音字／詞候選 → Jev 依上下文選擇 → 套件顯示候選」。若程式已提供正確修法，不需要另一個生成模型。若本機找不到修法，Jev 無法自行新增答案；可保留原文，或另外評估生成模型作為選配，並不限 Gemini。

先前 Gemini 基準版仍是現有套件的實作。**本次僅確認 Jev API 可用與候選判斷能力，尚未切換套件、部署 Jev 金鑰或實作本機候選引擎。** Jev 金鑰不能填入目前標示 Gemini 的欄位。

## 測試設定與結果

8 句人工構造開發例句，修正候選由開發者事先寫好。每次讓 Jev 選擇保留、採用修正或不確定；預期答案未傳入 API。沒有讀取或調整 holdout。

| 原文／檢查重點 | 提供的修法 | Jev 選擇 | 是否符合預期 |
|---|---|---|---|
| 請把這兩段連載憶起。 | 連載憶起 → 連在一起 | 採用 | 是 |
| 我明天在回覆你。 | 在 → 再 | 保留 | 否，漏判 |
| 我現在在家。 | 在家 → 再家 | 保留 | 是 |
| 我會再確認一次。 | 再 → 在 | 保留 | 是 |
| 這部小說正在連載。 | 連載 → 連在 | 保留 | 是 |
| 他忽然憶起往事。 | 憶起 → 一起 | 保留 | 是 |
| 請解釋「連載憶起」這個錯字。 | 引文改為連在一起 | 保留 | 是 |
| 王再興今天在家。 | 王再興 → 王在興 | 保留 | 是 |

- 8 次 API 全部成功，7 次選擇符合預期。錯句只有 2 句，其中修復 1 句；不可將整體 7/8 當成錯句修復率。
- API 往返 211–311 ms，中位數 245 ms；不是瀏覽器最後輸入到顯示的端到端延遲。
- 依回報輸入 tokens、[官方價格](https://docs.typesafe.ai/models) US$0.042／百萬輸入 tokens、估算匯率 35，合計 NT$0.00561393；供應商帳單仍為實際費用依據。
- 沿用既有 `.local/eval-budget.sqlite`，每次先預留 NT$0.20 再按 usage 結算，沒有另開預算。包含之前兩次 Gemini 失敗保留的 NT$0.40，累計估算／保守預留 NT$0.40561393。

這不是產品驗收：候選已預先給好，沒有量測候選涵蓋率；樣本很少、沒有真人語音資料、沒有達成 80%／99% 證據。Jev 的 confidence 是輸出分布的確定程度，不能直接當成這個中文校對產品的實測準確率。官方也提醒 [CJK 能力弱於英文](https://docs.typesafe.ai/models#language-support)。

下一階段應分開驗證本機候選能否包含正解，以及 Jev 能否從候選中選對；保留原文永遠是一個選項，品質未通過前不開自動修改。
